# Master's Data Science Projects

A collection of projects completed during my **Master of Data Science and Decisions at UNSW Sydney**, covering machine learning, statistical modelling, forecasting, econometrics, databases and data visualisation.

The repository showcases my experience applying **Python, R and SQL** to real-world analytical problems across energy, finance, housing, human activity, sports, education and consumer behaviour.

## Project Portfolio

| Project | Focus | Methods / Tools |
|---|---|---|
| ⚡ **Short-Term Electricity Demand Forecasting** | Forecasted electricity demand using historical demand, weather, calendar and lagged features, and compared predictive approaches. | Python, Time Series, ANN, LSTM, Feature Engineering |
| 📈 **Asset Return Analysis using Fama–French Factor Models** | Analysed Berkshire Hathaway excess returns and their relationship with systematic market risk factors. | Python, OLS, Fama–French Factors, Momentum, Newey–West Errors, VIF |
| 🏠 **Victoria Apartment Price Prediction** | Cleaned and integrated housing and demographic data to predict apartment prices and evaluate suburb-level investment opportunities. | R, Multiple Regression, Prediction Intervals, Data Cleaning, ggplot2 |
| 🐚 **Abalone Age Classification** | Classified abalones into age categories using physical characteristics and compared neural-network and baseline models. | Python, Neural Networks, Logistic Regression, Feature Engineering |
| 🚶 **Human Activity Recognition with Feature Selection** | Classified human activities from sensor data while comparing feature-selection and dimensionality-reduction approaches. | Python, Neural Networks, Feature Selection, SVD, Classification |
| 📡 **WiFi Localization & Credit Risk Classification** | Applied machine-learning classifiers to indoor WiFi localisation and credit-risk prediction problems. | Python, KNN, Naive Bayes, Decision Trees, Model Evaluation |
| 🗄️ **University Database Querying & Prerequisite Analysis** | Built SQL queries, views and functions to analyse enrolments, academic performance and direct/indirect prerequisite relationships. | PostgreSQL, SQL, PL/pgSQL, Joins, Views, Aggregation, Functions |
| 🏀 **NBA Player PCA Analysis** | Applied Principal Component Analysis to player attributes to examine dimensionality reduction, reconstruction and player patterns. | R, PCA, Eigenvalues, Covariance, Data Visualisation |
| 🍷 **Expert Reviews & Wine Demand** | Examined the causal impact of expert reviews on Swedish wine demand and explored substitution and product-differentiation effects. | Econometrics, Causal Inference, Fixed Effects, Distributed Lags |
| 📊 **Data Visualisation & Predictive Modeling** | Developed audience-focused visualisations and regression models across nutrition and bike-rental datasets. | R, ggplot2, Regression, Model Diagnostics |
| 📐 **Multivariate Data Analysis & Covariance Modeling** | Explored multivariate relationships, covariance structures, transformations and multivariate normal distributions. | R, Covariance, Correlation, Spectral Decomposition, Regression |
| 🎓 **College Admissions Distribution Analysis** | Compared probability models for college admissions data and evaluated predictions against observed outcomes. | R, Probability Distributions, Log Transformation, Statistical Modelling |
