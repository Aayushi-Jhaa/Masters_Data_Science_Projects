# Master's Data Science Projects

A collection of projects completed during my **Master of Data Science and Decisions at UNSW Sydney**, covering machine learning, statistical modelling, forecasting, econometrics and data visualisation.

## Projects

| Project | What I Did | Methods / Tools |
|---|---|---|
| ⚡ **Short-Term Electricity Demand Forecasting** | Forecasted electricity demand using historical demand, temperature, calendar and lag features, and compared forecasting approaches. | Python, Time Series, ANN, LSTM, Feature Engineering |
| 📈 **Asset Return Analysis using Fama–French Factor Models** | Analysed Berkshire Hathaway excess returns and their relationship with market risk factors. | Python, OLS Regression, Fama–French Factors, Econometrics |
| 🏠 **Victoria Apartment Price Prediction** | Cleaned and integrated apartment and demographic data, predicted future prices and evaluated suburb-level investment opportunities. | R, Regression, Prediction, Data Cleaning, ggplot2 |
| 🐚 **Abalone Age Classification** | Classified abalones into age groups using physical measurements and compared predictive models. | Python, Neural Networks, Logistic Regression, Feature Engineering |
| 🚶 **Human Activity Recognition with Feature Selection** | Classified human activities from sensor data while comparing feature-selection and dimensionality-reduction approaches. | Python, Neural Networks, Feature Selection, SVD |
| 📡 **WiFi Localization & Credit Risk Classification** | Applied classification algorithms to WiFi room localisation and credit-risk prediction problems. | Python, KNN, Naive Bayes, Decision Trees |
| 🏀 **NBA Player PCA Analysis** | Applied PCA to NBA player attributes to explore dimensionality reduction, reconstruction and patterns in player characteristics. | R, PCA, Eigenvalues, Covariance |
| 📊 **Data Visualisation & Predictive Modeling** | Created audience-focused visualisations and developed regression models for bike-rental demand. | R, ggplot2, Multiple Regression, Model Diagnostics |
| 📐 **Multivariate Data Analysis & Covariance Modeling** | Explored covariance structures, transformations, regression and multivariate normal distributions. | R, Covariance, Correlation, Spectral Decomposition |
| 🎓 **College Admissions Distribution Analysis** | Compared exponential and log-normal modelling approaches for college admissions data and evaluated their predictive accuracy. | R, Probability Distributions, Statistical Modelling |

## Technical Skills

**Programming:** Python, R, SQL  
**Machine Learning:** Regression, Classification, KNN, Naive Bayes, Decision Trees, Neural Networks, ANN, LSTM  
**Statistics:** PCA, probability modelling, covariance analysis, econometrics, model diagnostics  
**Data Science:** Data cleaning, EDA, feature engineering, time-series forecasting, model evaluation  
**Visualisation & Tools:** ggplot2, Matplotlib, Jupyter Notebook, R Markdown, Git/GitHub
